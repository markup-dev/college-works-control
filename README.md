## 🎯 О проекте

**College Works Control** — веб-система для управления учебными заданиями и проверкой работ в учебном процессе колледжа.

Платформа объединяет три роли (студент, преподаватель, администратор) в едином интерфейсе и автоматизирует ключевые процессы: учебные программы и специальности, назначение преподавателей на группы и дисциплины, выдачу заданий, отправку и проверку работ, переписку, уведомления, рассылки и администрирование пользователей.

Проект ориентирован на колледжи, кафедры и образовательные команды, которым важны прозрачность, контроль и удобство работы.

## ✅ Ключевые возможности

### Общие

- ✅ **Ролевая модель**: студент / преподаватель / администратор с разграничением API и UI.
- 🔔 **Уведомления**: список, счётчик непрочитанных, массовая отметка и очистка.
- 👤 **Профиль**: данные пользователя, смена пароля (включая принудительную при первом входе).
- 📢 **Платформенный баннер**: глобальное сообщение для аудитории (настраивается администратором).
- 🎨 **Интерфейс**: React, SCSS, адаптивная вёрстка, модальные окна, toast-уведомления.

### Студент

- 📋 **Задания**: список с фильтрами, статусы, дедлайны, блок «требует внимания» (пересдачи и сроки).
- 📤 **Сдача работ**: загрузка файла или отметка «готов к демонстрации»; поддержка chunk-upload для больших файлов.
- 📎 **Материалы заданий**: скачивание материалов преподавателя.
- 💬 **Сообщения**: переписка с преподавателем, архивация диалогов.
- 📊 **Результаты**: оценки, комментарии, история сдач.

### Преподаватель

- 📦 **Задания**: создание, редактирование, критерии оценки, материалы, форматы файлов, тип сдачи (файл / демонстрация).
- 🗂️ **Банк заданий**: заготовки для повторной выдачи группам без копирования вручную.
- 🚀 **Проверка работ**: оценка, комментарий, возврат на доработку, очередь сдач с фильтрами.
- 📈 **Аналитика**: успеваемость, активность, статистика по группам и периодам.
- 👥 **Группы и студенты**: обзор групп, карточки студентов, рассылка личных сообщений группе.
- 📚 **Дисциплины**: список назначенных дисциплин, заявки на допуск к дисциплине и назначение на группу (с документами).
- 💬 **Сообщения и рассылка**: переписка со студентами, напоминания о несданных работах.

### Администратор

- 📊 **Дашборд**: сводная статистика, график активности за неделю, последние события журнала.
- 👤 **Пользователи**: CRUD, сброс учётных данных, предупреждения, импорт из CSV.
- 🏫 **Группы**: CRUD, перевод курса, массовое добавление студентов, импорт CSV, карточка группы.
- 🎓 **Специальности**: учебные программы, синхронизация дисциплин по курсам.
- 📖 **Дисциплины**: CRUD, импорт CSV, допуски преподавателей к дисциплинам.
- 📌 **Назначения (teaching loads)**: кто ведёт дисциплину в группе; пакетное создание, перенос, модерация заявок преподавателей.
- 📝 **Задания (homework)**: обзор всех заданий в системе, смена преподавателя, фильтры.
- 📣 **Рассылки**: массовые уведомления пользователям.
- 📜 **Журнал**: системные логи с фильтрами и экспорт в CSV.
- ⚙️ **Настройки**: баннер, политика паролей, шаблон письма с учётными данными, параметры безопасности.

### Backend

- 📦 **API-first**: Laravel REST API + Sanctum, rate limiting, signed URLs для материалов.
- ✅ **Тесты**: набор PHPUnit feature-тестов (задания, сдачи, уведомления, заявки преподавателей и др.).

## 🚀 Начало работы (Getting Started)

### Требования

- `Node.js` (рекомендуется `20+`)
- `npm` (рекомендуется `10+`)
- `PHP` (`8.2+`)
- `Composer` (`2+`)
- `MySQL` (`8+`)
- Git

### Установка

```bash
git clone https://github.com/markup-dev/college-works-control.git
cd college-works-control
```

#### 1) Настройка backend (Laravel API)

```bash
cd backend
composer install
cp .env.example .env
php artisan key:generate
```

Отредактируйте параметры БД в `backend/.env`:

```env
DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=college_works_control
DB_USERNAME=root
DB_PASSWORD=
```

Примените миграции и сиды (демо-пользователи, группы, дисциплины, задания):

```bash
php artisan migrate --seed
```

Запустите API:

```bash
php artisan serve
```

На Windows можно запустить `serve.bat` в папке `backend`.

#### 2) Настройка frontend (React)

```bash
cd ../frontend
npm install
```

Создайте файл `.env` в `frontend`:

```env
REACT_APP_API_URL=http://localhost:8000/api
```

Запустите клиентское приложение:

```bash
npm start
```

### Сценарий пользователя

1. Откройте главную (`/welcome`) или страницу входа (`/login`).
2. Выберите роль и войдите (или используйте демо-аккаунт).
3. В кабинете:
   - **студент** (`/student`) — задания, сдача работ, сообщения, уведомления, профиль;
   - **преподаватель** (`/teacher`) — задания, банк заданий, проверка сдач, аналитика, группы, дисциплины, сообщения;

### Пример API-запроса (авторизация)

```bash
curl -X POST http://localhost:8000/api/login \
  -H "Content-Type: application/json" \
  -d "{\"login\":\"Administrator\",\"password\":\"Password123\",\"role\":\"admin\"}"
```

Ответ содержит токен Sanctum — передавайте его в заголовке `Authorization: Bearer <token>` для защищённых эндпоинтов.

